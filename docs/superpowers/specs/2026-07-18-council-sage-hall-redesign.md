### 3.2 关键体验点

1. **进入页面立刻**：5 议员按顺序 1.5s 间隔发"开始调研"开场白
   - 前端制造仪式感，不等后端
   - 文案模板：[议员名] "开始调研。[一句话定位，按思维模型]"
2. **调研中**：状态条头像加 spinner 环
3. **调研完一个议员**：把他的"开始调研"气泡替换为"调研完成 + 完整结论"
   - 后端 SSE 推到 `members_state[id]` 时触发替换
4. **用户插话**：写入群聊，右对齐深松绿气泡，下一轮议员会自然接住
5. **阶段切换**：居中系统消息"全部调研完成，进入第 N 轮辩论"
