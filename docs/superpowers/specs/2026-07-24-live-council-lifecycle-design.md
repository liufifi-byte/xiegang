# 实时专家议会生命周期与执行架构

## 目标

让用户进入会议后无需理解后台服务即可自动开始分析；会议状态真实、可恢复，专家结果逐个出现，并支持多个用户同时使用。

## 用户生命周期

- 用户进入会议后，会议任务立即进入执行队列。
- 刷新页面不结束会议，页面恢复数据库中的最新状态。
- 点击会议页左侧“返回首页”不结束会议；首页显示“继续正在进行的会议”。
- 用户点击“结束会议”时立即取消执行。
- 用户关闭标签页或离开本站后，若 20 秒内未重新连接，自动取消会议。
- 短暂断网、刷新或页面重新挂载在 20 秒宽限期内不误杀会议。
- 会议完成后，首页入口变为“查看分析结果”。

## 服务架构

API 与 Worker 是两个长期在线、职责独立的服务：

- API：创建会议、读取快照、处理心跳与取消、输出实时事件。
- Worker：领取排队任务、运行专家 Agent、工具调用、交叉回应和主席总结。

开发环境提供统一启动方式，同时启动当前项目目录下的 API、Worker 和前端。正式部署中 API 与 Worker 分别作为常驻服务运行。用户不需要手动启动或感知 Worker。

Worker 使用数据库队列领取任务，支持多个用户同时创建会议。单个 Worker 限制并发会议数；超过容量的会议继续排队，并向用户展示真实排队状态。

## 会议状态

数据库保存明确的阶段状态，前端不再根据零散事件猜测：

| 状态 | 用户文案 |
| --- | --- |
| `queued` | 已进入队列，等待分析服务 |
| `claimed` | 会议已开始，正在理解问题 |
| `researching` | 专家正在并行调研 |
| `cross_examining` | 分歧最大的专家正在交叉回应 |
| `summarizing` | 主席正在整理结论 |
| `done` | 议会报告已生成 |
| `cancelled` | 会议已结束 |
| `failed` | 本次分析未能完成 |

API 启动但 Worker 不在线时，页面必须显示“分析服务暂时不可用”，而不是无限展示“等待中”。

## 专家执行与增量展示

五位专家以独立、受预算约束的 ReAct Agent 并行执行。每位专家独立发出以下公开事件：

1. 开始思考
2. 选择并使用工具（如适用）
3. 整理证据
4. 完成或降级

每位专家完成时，Worker 立即把该专家的安全结果、证据摘要和指标写入数据库，并发出实时事件。前端在两秒内展示该专家观点，不等待其余专家完成。

慢专家在 45 秒后显示“分析时间较长，仍在继续”。达到硬上限后输出降级结果。至少三位专家完成后即可进入观点交锋，未完成专家停止或以已有安全结果参与，不能阻塞整场会议。

会议阶段之间仍然串行：

1. 理解问题
2. 五位专家并行调研
3. 选择分歧最大的三位专家
4. 三位专家并行交叉回应
5. 确定主席
6. 主席生成总结

## 心跳与自动取消

会议页周期性更新该设备在当前会议中的在线租约。正常刷新会在 20 秒内恢复租约。点击“返回首页”时，前端显式把会议标记为后台保留，首页继续发送低频心跳。

关闭标签页或离开本站后不再发送心跳；服务端在租约超过 20 秒后把会议标记为取消，并通知 Worker停止当前模型或工具任务。

浏览器关闭事件只用于加速提示，不作为唯一取消依据，避免刷新误杀。

## 首页入口

首页根据设备标识读取最近一场未结束或已完成但未查看的会议：

- 运行中：显示议题、当前阶段、完成专家数和“继续进入”。
- 已完成：显示“查看分析结果”。
- 已取消或失败：入口消失。

一期只显示一场最近会议，不引入完整历史会议系统。

## 会议页导航

- 删除左侧无功能圆圈。
- 使用语义明确的左箭头作为“返回首页”。
- 鼠标悬浮和无障碍标签均显示“返回首页”。
- “返回首页”和“结束会议”是两个独立操作。
- 不再使用容易被理解为收起侧栏的符号。

## 容错

- Worker重启后重新领取有效的排队任务，并回收超时的运行任务。
- 单个专家失败不影响其他专家。
- 至少三位专家产生有效结果时允许继续。
- 少于三位有效结果时明确失败，不生成伪完整报告。
- 所有恢复均以数据库快照和持久化事件为准。
- API、Worker或模型服务不可用时展示面向用户的可理解信息。

## 验收标准

1. 创建会议后，在线 Worker 无需用户操作自动领取。
2. 两个用户同时创建会议时分别执行，不混淆数据。
3. 排队、领取、调研、交锋、总结状态与后端一致。
4. 任意专家完成后两秒内出现在会议页面。
5. 刷新后会议继续，已有结果和状态不丢失。
6. 返回首页后可继续进入会议。
7. 点击结束后模型与工具调用停止。
8. 关闭标签页或离站超过 20 秒后会议取消。
9. API或 Worker 不可用时展示明确提示。
10. 左侧无无意义圆圈，返回按钮含图标和“返回首页”提示。
